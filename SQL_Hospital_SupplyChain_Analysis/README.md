# SQL_Hospital_SupplyChain_Analysis

## Overview

This project analyzes hospital supply chain and operational data using SQL queries executed in a Jupyter Notebook. The goal is to identify inventory risks, understand expense drivers, link patient care to staffing needs, evaluate vendor performance, and uncover operational inefficiencies.

The datasets include financial, inventory, patient, staff, and vendor information, enabling a comprehensive view of hospital operations and cost management.

## Key Features

- Inventory risk assessment to prevent stockouts  
- Expense category and monthly spending trend analysis  
- Patient procedure length-of-stay and staffing correlation  
- Vendor lead time and cost impact evaluation  
- Operational inefficiency detection through staff overtime and equipment usage analysis  

## Technologies Used

- SQLite for database management  
- SQL for data querying and aggregation  
- Python (Pandas) for data extraction and manipulation  
- Jupyter Notebook for an interactive analysis report  

## How to Use

1. Clone the repository to your local machine.  
2. Open the Jupyter Notebook file:  
   [SQL_Hospital_SupplyChain_Analysis.ipynb](https://github.com/meenakshisharadha/analytics-portfolio/blob/main/SQL_Hospital_SupplyChain_Analysis/notebooks/SQL_Hospital_SupplyChain_Analysis.ipynb)  
3. Ensure you have SQLite and necessary Python dependencies installed (`pandas`, `sqlite3`).  
4. Run the notebook cells sequentially to reproduce the analysis.  
5. Explore the SQL queries and Markdown explanations for detailed business insights.  

## Project Structure

- `SQL_Hospital_SupplyChain_Analysis.ipynb` — Main notebook with SQL queries and business interpretations
