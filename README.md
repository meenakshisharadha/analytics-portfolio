# Meenakshi Sharadha — Data Analytics Portfolio

Welcome! This repository highlights real-world projects showcasing a blend of data engineering, advanced analytics, and machine learning to drive measurable business outcomes.

---

## Core Competencies

- **Data Engineering & ETL:** pandas, NumPy, SQL, data validation, pipeline automation  
- **Exploratory Analysis & Visualization:** Matplotlib, Seaborn, Plotly  
- **Statistical & Analytical Rigor:** IQR outlier detection, hypothesis testing, cohort analysis  
- **Unsupervised Learning:** RFM-driven K-Means clustering for precise customer segmentation  
- **Supervised Learning:** Random Forest, logistic regression for churn prediction and risk scoring  
- **Feature Engineering & Scoring:** Custom Customer Value Score, time-based aggregations  
- **Model Evaluation & Tuning:** Cross-validation, classification metrics, ROC AUC  
- **Business Storytelling:** Executive summaries, ROI analysis, strategic recommendations

## Featured Projects

### 1. [Strategic Customer Analytics](https://github.com/meenakshisharadha/analytics-portfolio/blob/main/Customer-Analytics-RFM-Clustering/notebooks/Customer_Analytics_RFM_Clustering_Churn.ipynb)

- **Dataset:** UCI Online Retail (450K+ transactions)  
- **Highlights:** Data cleaning with robust IQR filtering, RFM segmentation, K-Means clustering, Random Forest churn prediction achieving 85%+ accuracy  
- **Business Impact:** Identified VIP customer segments, designed retention campaigns, uncovered cross-sell opportunities resulting in estimated £320K revenue uplift  

### 2. [SQL Hospital Supply Chain Analysis](https://github.com/meenakshisharadha/analytics-portfolio/blob/main/SQL_Hospital_SupplyChain_Analysis/notebooks/SQL_Hospital_SupplyChain_Analysis.ipynb)

- **Dataset:** Linked hospital financial, inventory, patient, staff, and vendor data  
- **Highlights:** Inventory risk prediction, expense trend analysis, staffing-patient care correlations, vendor performance evaluation, operational inefficiency detection with actionable SQL-driven insights  
- **Business Impact:** Recommendations for optimizing hospital inventory, controlling costs, improving staffing allocation, and managing vendor risks
